
# Cricket – Complete Guide

Cricket is a popular team sport played between two teams of eleven players each. The game is played using a bat and ball on a circular or oval-shaped ground with a rectangular pitch in the centre.

Cricket is governed internationally by the International Cricket Council (ICC).

## 1. History of Cricket

Cricket originated in England during the 16th century. Over time, it became popular in countries such as India, Australia, England, Pakistan, South Africa, and New Zealand.

The first international cricket match was played between Canada and the United States in 1844.

### 1.1 International Cricket Council

The ICC is the global governing body of cricket.

Its major responsibilities include:

- Organizing international tournaments.
- Maintaining cricket rules and regulations.
- Managing international team rankings.
- Promoting cricket worldwide.

## 2. Formats of Cricket

There are three major formats of international cricket.

### 2.1 Test Cricket

Test cricket is the longest format of the game.

- Each team gets two innings.
- A match can last up to five days.
- There is no fixed over limit.
- Players require patience and consistency.

### 2.2 One Day International (ODI)

ODI cricket is a limited-overs format.

- Each team gets 50 overs.
- Each team generally has eleven players.
- The team scoring more runs wins.
- ICC Cricket World Cup is played in this format.

### 2.3 Twenty20 (T20)

T20 is the shortest international format.

- Each team gets 20 overs.
- Each innings lasts approximately three hours or less.
- Batting aggression and bowling variations are important.
- ICC T20 World Cup is a major international tournament.

## 3. Basic Rules of Cricket

Cricket is played between two teams.

The main objective is to score more runs than the opponent.

### 3.1 Scoring Runs

Players can score runs through:

1. Running between the wickets.
2. Hitting boundaries.
3. Hitting sixes.
4. Extra runs awarded by the umpire.

### 3.2 Types of Dismissals

A batsman can get out in several ways:

- Bowled
- Caught
- LBW (Leg Before Wicket)
- Run Out
- Stumped
- Hit Wicket

## 6. Cricket Statistics

Cricket uses several statistics to measure player performance.

### Batting Average

Batting average measures how many runs a batsman scores per dismissal.

Formula:

Batting Average = Total Runs / Number of Times Dismissed

### Bowling Average

Bowling average measures the number of runs conceded per wicket taken.

Formula:

Bowling Average = Total Runs Conceded / Total Wickets

### Strike Rate

Strike rate measures scoring speed.

For batting:

Strike Rate = (Total Runs / Balls Faced) × 100

For bowling:

Bowling Strike Rate = Balls Bowled / Wickets Taken

## 8. Example Python Code

The following code calculates a cricket player's batting average.

```python
def batting_average(total_runs, dismissals):

    if dismissals == 0:
        return 0

    average = total_runs / dismissals

    return round(average, 2)


runs = 1200
dismissals = 30

average = batting_average(runs, dismissals)

print("Batting Average:", average)
```

Output:

```text
Batting Average: 40.0
```
